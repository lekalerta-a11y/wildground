# Contributing

Use Node.js 22.12+. Run `npm ci`, `npm test` and `npm run build`. Keep bots behind the BotBrain interface and rules in src/core.

Describe the visible result and relevant checks in pull requests. Include screenshots for UI work. Never commit wallet recovery phrases, private keys, tokens or environment secrets. Changes to the WG mint, threshold or live title need a specific project decision.

The project has no selected license. Contact the maintainer before external reuse.
